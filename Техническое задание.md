# План разработки проекта «Культ» (MVP 1.0)

## Этап 1. Подготовка архитектуры, инфраструктуры и базовых сервисов

### 1. Общая концепция

Культовая связь — интеллектуальная социальная сеть нового поколения для знакомств, общения и построения отношений.
**Основная задача платформы:**
- [ ]Не искать максимальное количество совпадений.
- [ ]А находить максимально совместимых людей.
Главным инструментом является искусственный интеллект, который анализирует интересы, ценности, стиль жизни, особенности личности и помогает людям строить качественные отношения.

Платформа включает:
- [ ]знакомства;
- [ ]социальную сеть;
- [ ]внутренний мессенджер;
- [ ]ИИ-помощника;
- [ ]офлайн-мероприятия;
- [ ]сообщества;
- [ ]рекомендации.

### 2. Платформы

Разработка должна предусматривать:
- [ ]PWA
- [ ]Web
- [ ]Android
- [ ]iOS
Все на едином API.

### 3. Технологическая архитектура
- [ ]**Frontend:** Next.js (React), TypeScript, Tailwind CSS, PWA.
- [ ]**Backend:** NestJS (TypeScript) с REST API и WebSocket для чатов.
- [ ]**База данных:** PostgreSQL.
- [ ]**Кэш и очереди:** Redis + BullMQ.
- [ ]**Хранилище файлов:** S3-совместимое объектное хранилище.
- [ ]**Поиск:** Elasticsearch/OpenSearch.
- [ ]**ИИ-модуль:** LLM через собственный сервис с возможностью подключения разных моделей, отдельный сервис рекомендаций и RAG для персональных подсказок.
- [ ]**Уведомления:** Firebase Cloud Messaging, Apple Push Notification Service, Web Push.
- [ ]**Видео и голос:** WebRTC.
- [ ]**Мониторинг:** Prometheus + Grafana.
- [ ]**Логирование:** Loki/ELK.

## Этап 4. Поиск, Алгоритмы ИИ-подбора и уникальный механизм подборок

### 1. Поиск (Фильтры)

Возраст, Рост, Вес, Расстояние, Дети, Хочу детей, Интересы, Темперамент, Доход (по желанию), Знак зодиака, Профессия, Язык, Хобби, Образование, Домашние животные, Наличие автомобиля, Путешествия, Верификация, Онлайн, Премиум.

### 2. ИИ-подбор

Основной алгоритм продукта.
**ИИ анализирует:**
интересы, ценности, психотип, тип личности, манеру общения, язык любви, темперамент, знак зодиака, лунный знак, ритм жизни, активность, совместимость целей, планы на будущее, наличие детей, религиозность, музыкальные вкусы, любимые фильмы, любимые книги, путешествия, географию, возраст, время активности, эмоциональный интеллект, юмор и десятки других факторов.
**ИИ выдает:** Процент совместимости, подробное объяснение.

*Например:*
> “У вас совпадают жизненные цели.
> Вы оба предпочитаете спокойный отдых.
> Одинаковый уровень эмоциональности.
> Различается отношение к финансам.”

### 3. Идея, способная выделить проект среди конкурентов

Вместо бесконечного механического свайпа внедрить ежедневную интеллектуальную подборку. Один раз в сутки пользователь получает 3–5 новых рекомендаций, подобранных ИИ по глубокой совместимости. Каждая карточка сопровождается объяснением, почему именно этот человек оказался в подборке: общие ценности, схожий образ жизни, совпадающие интересы, сильные и потенциально дополняющие друг друга качества.

Такой подход делает знакомство более осмысленным, снижает усталость от бесконечного выбора и формирует у пользователей ощущение, что каждая рекомендация действительно заслуживает внимания. Именно эта философия может стать главным конкурентным преимуществом «Культовой связи».

## Этап 8. Стратегия масштабирования в экосистему («Культ»)

### Архитектура экосистемы

Я бы сразу проектировал платформу не как одно приложение, а как экосистему под брендом «Культ», где знакомства являются лишь одной из частей.

В будущем пользователь входит под одной учетной записью и получает доступ ко всем сервисам:
1. **Культовая связь.** Социальная сеть, знакомства, мессенджер и ИИ.
2. **Культовые подкасты.** Видео и аудиоконтент, рекомендации выпусков по интересам пользователя.
3. **Академия твоего будущего.** Онлайн-обучение, где ИИ может рекомендовать курсы, исходя из целей и интересов человека.
4. **Культовые события.** Афиша мероприятий, встречи, путешествия и клубные активности.
5. **Культ Маркет (перспектива).** Маркетплейс товаров и услуг от участников сообщества.
6. **Культ AI.** Единый интеллектуальный помощник, который сопровождает пользователя во всех сервисах, запоминает его интересы, помогает знакомиться, учиться, планировать встречи и взаимодействовать с другими людьми.
