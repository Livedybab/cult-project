# 🌟 КУЛЬТ — интеллектуальная социальная сеть для знакомств и общения

**Культ** — это больше, чем барбершоп. Это экосистемный проект, объединяющий сообщество единомышленников, стильный барбершоп и **Культовые знакомства** — интеллектуальную платформу для поиска совместимых людей на основе ИИ-анализа интересов, ценностей и психотипов. Проект реализован на **Django** с использованием **SQLite**, адаптивной вёрсткой и премиальным тёмным дизайном.

---

## 🚀 Быстрый старт

1. Клонируйте репозиторий: `git clone https://github.com/ваш_логин/cult-project.git` и перейдите в папку `cd cult-project`.
2. Создайте и активируйте виртуальное окружение: `python -m venv venv`, затем `venv\Scripts\activate` (Windows) или `source venv/bin/activate` (Linux/Mac).
3. Установите зависимости: `pip install -r requirements.txt`.
4. Выполните миграции: `python manage.py makemigrations dating` и `python manage.py migrate`.
5. Создайте суперпользователя для админки: `python manage.py createsuperuser`.
6. Запустите сервер: `python manage.py runserver`. Откройте в браузере `http://127.0.0.1:8000/`.

---

## 📁 Структура проекта

- `manage.py` – точка входа.
- `cult/` – настройки Django.
- `main/` – приложение главной страницы (лендинг).
- `dating/` – основное приложение «Культовые знакомства» (модели: Profile, Interest, Value, CharacterTrait, Photo, Like, Chat, Message, DailyPick, Group; вьюхи: свайп, чаты, онбординг, профиль, группы, подборка; формы, урлы, шаблоны).
- `static/` – CSS, JS, изображения.
- `templates/` – общий базовый шаблон.
- `media/` – загруженные аватары и фото.

## 🧩 Основные возможности

### Главная страница (лендинг)
- Баннер с описанием проекта, кнопка «Создать профиль».
- Три показателя совместимости (интересы, психотипы, ценности).
- Блок «Как это работает» с иконками.

### Культовые знакомства (раздел `/dating/`)
- **Отдельная система регистрации/входа** (не зависит от основного сайта).
- **Пошаговый онбординг** (4 шага: основные данные, цели, интересы/ценности, черты характера).
- **Свайп** (лайк/дизлайк с анимацией, взаимные лайки → создание чата).
- **Чаты** с автоматическим обновлением сообщений (polling).
- **Профиль** с аватаром, галереей фото, интересами, ценностями, чертами характера и процентом совместимости.
- **Группы по интересам** (вступление, просмотр участников).
- **Ежедневная ИИ-подборка** (5 рекомендаций в сутки).

## 🛠 Технологический стек

- **Backend:** Python 3.12, Django 6.1.
- **База данных:** SQLite.
- **Frontend:** HTML5, CSS3, JavaScript (адаптив).
- **Шрифты:** Cormorant Garamond, Inter.
- **Иконки:** Font Awesome 6.
- **Обработка изображений:** Pillow.
- **Карты:** Яндекс.Карты (iframe).

---

## 🔐 Административная панель

Доступна по адресу `/admin/` (суперпользователь создаётся через `createsuperuser`). Управляемые модели: пользователи, профили, интересы, ценности, черты характера, фото, лайки, чаты, сообщения, группы, ежедневные подборки.

## 📦 Установка зависимостей
